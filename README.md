# Interior Point Nepal
This is a website redesign of a interior designing company.

## Tech Stack
- **Frontend:** HTML, CSS, and lil bit of JavaScript

## Intructions to open website
- Open any browser you like
- Search interiorpointnepal.netlify.app
- then wallah. The website is open
### But if you want to get the code and see on your local device
- Open github
- Search rojen-chakradhar
- Go to repository
- Find Interior Point Nepal and open it
- Then clone the repository
- Then run index.html file
- And wallah. The website is open

## 🎨 Features
- Minimalism
- Fully responsive layout for all devices
- Working slider to see the projects.
- Clean, modern design with focus on visuals and UX
